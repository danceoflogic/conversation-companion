# SWOT Analysis

## Strengths
- Strong product concept with obvious demo value
- Broad applicability across tutoring, meetings, and accessibility
- Interactive information display creates visible user value quickly
- Compatible with local-first and cloud-augmented architectures
- Natural synergy with future maths tutoring positioning

## Weaknesses
- Complex pipeline: audio, transcription, reasoning, and UI orchestration
- Real-time systems are harder to make reliable than request-response apps
- High risk of feature sprawl if the scope is not constrained
- Output quality depends heavily on transcription quality and model accuracy
- Local hardware may limit performance for fully local inference

## Opportunities
- Study companion and tutoring augmentation market
- Accessibility use cases for conversation support and summarisation
- Meeting companion productization
- B2B education partnerships
- Hybrid architecture: premium cloud quality with local/private mode fallback

## Threats
- Privacy and legal concerns around ambient listening
- User distrust if consent and visibility are poorly handled
- Large platform competitors can replicate generic versions quickly
- High compute costs if cloud-heavy usage scales without guardrails
- Hallucination or misleading information in live educational contexts

## Strategic Conclusion
The strongest route is a focused vertical MVP in tutoring/study support with explicit controls, visible listening states, and a modular backend. The most dangerous failure mode is trying to build a universal ambient assistant too early.
