# Roadmap

## Delivery Model
Agile, milestone-based, with formal gates between phases.

## Phase 0 — Discovery and Definition
Deliverables:
- project charter
- SWOT
- PRD
- architecture draft
- safety/privacy protocol
- backlog and release plan

Exit criteria:
- scope agreed
- MVP vertical selected
- technical approach documented

## Phase 1 — Foundation / Prototype (`0.1.x`)
Goals:
- repository bootstrap
- app shell
- transcript ingestion path
- mock structured widget renderer

Exit criteria:
- local development environment bootstraps cleanly
- mock transcript can drive UI widgets

## Phase 2 — End-to-End Alpha (`0.2.x`)
Goals:
- microphone capture
- chunked transcription
- context engine
- structured JSON validation
- live UI updates

Exit criteria:
- first real spoken session demo works

## Phase 3 — Tutoring-Focused MVP (`0.3.x` to `0.5.x`)
Goals:
- tutoring-oriented widgets
- export and session controls
- error handling and retries
- privacy settings
- internal alpha feedback loop

Exit criteria:
- stable tutoring workflow end to end

## Phase 4 — Beta Hardening (`0.6.x` to `0.9.x`)
Goals:
- performance tuning
- observability
- user testing
- deployment pipeline
- retention/deletion controls

Exit criteria:
- release candidate quality

## Phase 5 — Public v1.0
Goals:
- production readiness
- installation and onboarding flow
- support docs
- release notes

Exit criteria:
- signed-off release checklist
- monitored deployment
